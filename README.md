# Китай, концепт один

Проект «Китай Go», версия V1. Адаптивная вёрстка с анимацией для desktop, tablet и mobile.

Вёрстка трёх блоков Figma `4ucswRvxD8cmx9S9rNB8rV`, фрейм `1:6`, от 27.10.2026. Чистые HTML, CSS и JavaScript, без сборочного фреймворка и библиотек анимации.

Запуск: `node server.mjs`, затем http://localhost:4173/. Исходники страницы — `dist/`. Оптимизированная папка публикации — `out/`, обновляется командой `node prepare-release.mjs`. Предыдущая техническая папка `release/` сохранена. Шрифты и картинки локальные; временных Figma URL в рабочем коде нет. Исходные PNG сохранены и исключены из публикации.

## Поведение

- Первый экран: единичное появление текста с задержками 80–650 мс, иллюстрации билета — 1500 мс с поворотом 1,4° и сдвигом 18 px. Исходная иллюстрация единым растром, поэтому её части не имитируются отдельными слоями.
- Остальные блоки: IntersectionObserver, появление один раз на 18–24 px, затем наблюдение отключается. Скролл остаётся нативным; scroll hijacking, sticky-сцен и бесконечных фоновых циклов нет.
- Направления: клик и клавиатура, загрузка и декодирование следующего изображения до плавной смены; устаревшие асинхронные запросы не заменяют новый выбор.
- Туры: нативная горизонтальная прокрутка со scroll-snap. Десктоп — стрелки, мобильный — свайп и три точки. Высота следует самой высокой карточке, фото не растягивает ленту.
- Мобильное меню, клавиатурный фокус, диалоги с Escape, закрытие снаружи и возврат фокуса. `prefers-reduced-motion` отключает анимации и плавную прокрутку.

## Адаптация

Мобильного образца и мобильных текстовых стилей в Figma не было. Предложена адаптация с сохранением ролей: hero h1 80 → 34–54 px, заголовок раздела 60 → 30–42 px, название направления 60 → 36 px, название тура 24 → 17 px, цена 36 → 27 px. Боковые поля 20 px (320 px — 16 px), крупные отступы секций 64 px, карточки выходят за край без внутреннего белого зазора. Эти размеры предложены для вёрстки, а не выданы за существующие мобильные токены.

Их происхождение не подтверждено как документальная фотосъёмка; в Figma часть слоёв названа «ии». Новые изображения не генерировались. Для состояний направлений использованы настоящие фотографии Unsplash; источники приведены в `Источники изображений.md`. Персонажи из макета не подтверждены как реальные сотрудники.

## Границы V1

Телефон в макете демонстрационный. Реальные контакты, URL мессенджеров, страницы отзывов/блога/о компании, подробные программы и бронирование не предоставлены. Соответствующие кнопки открывают явное пояснение, а не ведут на выдуманный номер. Кнопка «Подобрать тур» ведёт к доступным карточкам. Данных посетителя страница не отправляет. Включён `noindex,nofollow`.

Шесть связей Code Connect согласованы пользователем; Figma не сохранила их из-за ограничения тарифа Organization/Enterprise. Карта сохранена в `reference/code-connect-mappings.json`; это не подтверждение сохранения связей на сервере Figma.
