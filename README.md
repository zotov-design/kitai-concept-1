# Китай, концепт один

Проект «Китай Go», версия V1. Адаптивная вёрстка с анимацией для desktop, tablet и mobile.

Клиентская демонстрация без входа: https://zotov-design.github.io/kitai-concept-1/ . Актуальная ревизия 27.10.2026: ховеры с инверсией, мобильные направления с фотографиями слева, пять туров и перетаскивание мышью.

Вёрстка трёх блоков Figma `4ucswRvxD8cmx9S9rNB8rV`, фрейм `1:6`, от 27.10.2026. Чистые HTML, CSS и JavaScript, без сборочного фреймворка и библиотек анимации.

Запуск: `node server.mjs`, затем http://localhost:4173/. Исходники страницы — `dist/`. Оптимизированная папка публикации — `out/`, обновляется командой `node prepare-release.mjs`. Предыдущая техническая папка `release/` сохранена. Шрифты и картинки локальные; временных Figma URL в рабочем коде нет. Исходные PNG сохранены и исключены из публикации.

## Поведение

- Первый экран: единичное появление текста с задержками 80–650 мс, иллюстрации билета — 1500 мс с поворотом 1,4° и сдвигом 18 px. Исходная иллюстрация единым растром, поэтому её части не имитируются отдельными слоями.
- Остальные блоки: IntersectionObserver, появление один раз на 18–24 px, затем наблюдение отключается. Скролл остаётся нативным; scroll hijacking, sticky-сцен и бесконечных фоновых циклов нет.
- Направления: на desktop синий фон только при hover/focus-visible, без выбранного состояния по клику; фотография меняется по наведению/фокусу после декодирования. На mobile у каждой строки квадратная фотография слева и уменьшенное название; большая фотография скрыта, ховер отсутствует. Ссылки в этой одностраничной демонстрации ведут к турам; реальные URL отдельных страниц направлений ещё не предоставлены.
- Туры: пять карточек. Десктоп — стрелки и перетаскивание зажатой левой кнопкой мыши без рывка при отпускании; реальный drag не открывает карточку. Мобильный — нативная прокрутка со scroll-snap и пять точек. Высота следует самой высокой карточке, фото не растягивает ленту. Между стрелками нет разделителя и круглой hover-заливки.
- Мессенджеры: неподвижные кнопки, на desktop при наведении белый фон и синий знак `#0372ff`. «Подобрать тур»: белый фон и синий текст при наведении. На touch-макетах hover не применяется.
- Мобильное меню, клавиатурный фокус, диалоги с Escape, закрытие снаружи и возврат фокуса. `prefers-reduced-motion` отключает анимации и плавную прокрутку.

## Адаптация

Мобильного образца и мобильных текстовых стилей в Figma не было. Предложена адаптация с сохранением ролей: hero h1 80 → 34–54 px, заголовок раздела 60 → 30–42 px, название направления 60 → 28 px (360–389 px — 26 px, до 359 px — 24 px), название тура 24 → 17 px, цена 36 → 27 px. Фотографии направлений 72 × 72 px, на 320 px — 64 × 64 px. Справа от каждого названия размещена стрелка в белом круге 32 × 32 px, выровненная по центру строки заголовка. Описание использует оставшуюся ширину под названием и стрелкой. Боковые поля 20 px (320 px — 16 px), крупные отступы секций 64 px, карточки выходят за край без внутреннего белого зазора. Эти размеры предложены для вёрстки, а не выданы за существующие мобильные токены.

Скругление синей hover-плашки desktop постоянно задано на отдельном фоновом слое. При наведении меняется только его цвет; перехода от прямых углов к скруглённым нет. Обычные разделители строк остаются прямыми.

## Границы V1

Телефон в макете демонстрационный. Реальные контакты, URL мессенджеров, страницы отзывов/блога/о компании, подробные программы и бронирование не предоставлены. Включён `noindex,nofollow`.

Дополнительные карточки «Чэнду и панды» и «Горы Чжанцзяцзе» демонстрационные; длительность и стоимость обозначены «по запросу», коммерческие условия не выдуманы.
